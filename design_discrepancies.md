# Расхождения дизайна: KayFit vs FitKeep vs Merged (Variant B)

Документ составлен на основе:
- `kayfit_screens.html` — оригинальный KayFit 2.0 (6 экранов)
- `design-kit.html` — оригинальный FitKeep (16 экранов)
- `kayfit_clickable_B.html` — итоговый прототип Variant B (кликабельный)
- `chat1.md` — переговоры с дизайн-агентом

Статусы решений: **ПРИНЯТО** | **ОТКРЫТ** | **ТРЕБУЕТ ПРОВЕРКИ**

---

## 1. Цветовая система / Brand Color

| Аспект | KayFit | FitKeep | Merged B |
|--------|--------|---------|----------|
| Primary | `#2563EB` синий | `#01BB16` зелёный | `#2563EB` синий |
| Акцент | Coral (`#F97316 → #F43F5E`) | Синий `#4E7EFB` | Coral + Violet для карточек тренировок |
| Фон | `#FFFFFF` белый | `#F5F5F5` светло-серый | `#FFFFFF` белый |
| Тема | Светлая | Светлая | Светлая |
| Active/Selected | синий | зелёный | синий |

**Решение:** ПРИНЯТО — везде KayFit Blue `#2563EB`, зелёный FitKeep убран полностью.

**Требует проверки:** Кнопка "Выполнено" в live-workout в FitKeep была зелёной. В merged — синяя. Нужно убедиться что это выглядит органично.

## 2. Нижняя навигация (TabBar)

| Аспект | KayFit | FitKeep | Merged B |
|--------|--------|---------|----------|
| Структура | Журнал \| + \| Чат (3+центр?) | Главная \| Тренировки \| Чат \| Ещё (4 таба) | Журнал \| + \| Чат (2 таба + центральная кнопка) |
| Центральная кнопка | Синий круг 50px, shadow | Нет | Синий круг, открывает Чат |
| Действие "+" | Bottom sheet с 4 опциями | — | Открывает Чат напрямую |
| Иконки | SVG line-icons (journal grid, speech bubble) | Эмодзи / font-icons | SVG line-icons из KayFit дизайн-системы |
| Активный стиль | Синий цвет иконки + label | Зелёный + underline dot | Синий цвет иконки + label |
| Таб "Ещё" | Неизвестно (был?) | Есть (More screen) | Убран, заменён аватаром в AppBar |

**Решение:** ПРИНЯТО — 2 таба + центральная «+» как в KayFit. Таб «Ещё» убран.

**Открытый вопрос:** В одном из промежуточных вариантов был таб «Тренировки». В финале его нет — тренировки доступны только через Журнал. Это сознательное решение? Нужен ли быстрый доступ к списку тренировок?

## 3. Журнал (главный экран)

| Аспект | KayFit | FitKeep | Merged B |
|--------|--------|---------|----------|
| Название таба | «Журнал» | «Главная» | «Журнал» |
| Иконка | SVG grid (rect + lines) | Эмодзи / font | SVG grid из оригинала |
| Верхний блок | CalendarStrip (неделя) | WeekStrip (неделя, другой стиль) | CalendarStrip из KayFit |
| Состояния дней | logged (зелёная рамка) / missed (красная) / active (синий кружок) | today (зелёный кружок) | Как в KayFit |
| Индикатор тренировки в календаре | Нет | Есть (зелёная точка) | ОТКРЫТ — в Variant B не реализовано |
| Макросы | 4 кольца SVG (calories/protein/carbs/fat) + легенда с числами | Нет | 4 кольца + крупное число ккал слева |
| Список еды | Плоский список: name / тип·время / kcal | Нет еды в журнале | Секция «Еда» (сворачиваемая), плоский список как в KayFit |
| Тренировки в журнале | Нет | Отдельный экран «Тренировки» | Секция «Тренировки» (сворачиваемая), показывает одну на сегодня + «Следующая:» |
| Группировка еды по приёмам | Была (завтрак/обед/ужин) | — | Плоский список без групп (упрощено в ходе итераций) |

**Решения:**
- ПРИНЯТО — 4 кольца макросов из KayFit
- ПРИНЯТО — плоский список еды как в KayFit
- ПРИНЯТО — тренировка на сегодня вместо «всего подряд»
- ОТКРЫТ — нужна ли группировка еды по приёмам пищи (Завтрак / Обед / Ужин)?
- ОТКРЫТ — нужен ли визуальный индикатор тренировки в CalendarStrip?

- ОТКРЫТ — из 9 шагов FitKeep реализованы только 2. Что брать? Рекомендация:
  - **Взять:** AI Consent (юридически важно), Quiz цели, Equipment, Way to Goal (параметры тела)

## Рекомендации по открытым вопросам

### Высокий приоритет (нужно решить до разработки)

**#15 — Таб «Тренировки»:** В финальном Merged тренировки доступны только через Журнал. Это скрывает ключевый функционал FitKeep. Рекомендация — вернуть таб: `Журнал | Тренировки | + | Чат` (4 элемента).

**#17 — Barcode Scanner:** Ключевая фича KayFit, отсутствует в Merged. Нужно добавить точку входа (через чат или кнопку в секции Еда).

**#13 — Индикатор тренировки в календаре:** Без него непонятно когда была тренировка. Рекомендация — добавить маленькую синюю точку под числом дня.

### Средний приоритет

**#14 — Группировка еды:** Плоский список теряет контекст (завтрак/обед). Рекомендация — вернуть секционные заголовки (Завтрак / Обед / Ужин / Перекус).

**#19 — Онбординг:** Минимальный флоу для запуска: Модули → Quiz (цель) → Параметры тела → Equipment → AI Consent. Body Form, Reward, Phone — опционально.

### Низкий приоритет

**#20 — Экран Плана:** Достаточно Settings → Программа для первой версии.

**#24 — Табы Мои/Все:** Только когда появятся готовые программы от команды (не только AI-генерация).
